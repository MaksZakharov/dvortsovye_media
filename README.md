# dvortsovye_media

Публичное хранилище иллюстраций к статьям канала **«Дворцовые судьбы»** — [dzen.ru/dvortsovye_sudby](https://dzen.ru/dvortsovye_sudby).

Здесь лежат только картинки: кадры к статьям и обложки. Тексты, планы и проверки — в отдельном (закрытом) репозитории канала. Файлы отсюда вставляются в статьи Дзена прямыми ссылками:

```
https://raw.githubusercontent.com/MaksZakharov/dvortsovye_media/main/Статьи/<slot_id>/<файл>
```

## Структура

```
Статьи/
  <slot_id>/                  слот контент-плана, например 2026-11-01-С1
    cover_<sha1[:8]>.jpg      обложка 1920×1080 (имя по содержимому: новая обложка — новый файл)
    01_<кто_или_что>.jpg      кадры в порядке появления в статье
    02_….jpg
    cover_hooks.json          факт для обложки, варианты, выбор (шаг 06О)
    cover_v2_не_выбран.jpg    невыбранный вариант обложки
```

`slot_id` — значение строки `| slot |` из plan-slot статьи (дата выхода + буква канала + номер: `2026-11-01-С2`). Номера кадров и подписи — из `images/image_manifest.md` статьи.

Файлы загружает скрипт `Скрипты/article_media.py` репозитория канала. Уже лежащий файл не перезаписывается и не удаляется: исправленный кадр получает новое имя.

## Правило иллюстраций и подписей

- **Реальные люди и реальные места** — только изображения в общественном достоянии (Public domain, CC0) или под свободной лицензией CC BY / CC BY-SA, в основном с Wikimedia Commons. NC, ND и fair use не берём. Подпись под кадром в статье — с атрибуцией: «Кто или что. Художник или фотограф, год. Музей / Wikimedia Commons, лицензия».
- **Сгенерированные картинки не используются** (Макс 26.10.2026, Система v06): прежние `_gen_` кадры перенесены в `_архив/`.
- **Обложка** — только подлинный портрет, гравюра или картина эпохи (одна или две рядом, края — размытая копия той же картины), без текста; подпись — атрибуция использованных портретов.

Лицензии исходных изображений сохраняются за их авторами; для CC BY-SA производные кадры распространяются на тех же условиях.
